应用搬家 / 卸载

把 C 盘软件整体搬到其他磁盘（原位置创建目录联接，软件无感知、可还原），或直接卸载不需要的软件。搬家前请完全退出目标软件（含托盘图标）。
搬到：
应用名称版本 占用 ⇅ 状态安装位置
已搬家记录（选中后可一键还原）
应用大小 原位置现位置时间

垃圾清理

扫描常见垃圾文件位置，勾选后一键清理。默认勾选项均可安全删除；被占用的文件会自动跳过。

空间分析

扫描磁盘或目录，用矩形树图/目录树直观展示空间去向。矩形树图中：单击进入目录，右键返回上级；目录树中：单击展开，双击打开。

大文件查找

找出磁盘上体积最大的文件。删除默认放入回收站，可反悔。系统关键文件（Windows 目录内）已自动排除。
大于
大小 文件名位置 修改时间

重复文件

按「大小 + 内容哈希」找出重复文件。每组默认保留第一个，其余可勾选删除（放入回收站）。建议对下载、图片、视频等目录使用。
大于

启动项管理

管理开机自启动（注册表、启动文件夹、计划任务）。禁用会自动备份、可随时恢复；不确定的项目建议先禁用观察。
状态名称 启动命令 / 任务路径来源

微信 / QQ 专项清理

扫描微信、QQ 数据目录并按类型列出。「缓存」可安全清理；「聊天/数据文件」含收发的原始文件，删除后无法从本机找回。清理前建议退出微信/QQ。
应用 类型 大小 ⇅ 路径

系统加速

查看占用内存最多的进程，一键释放各进程的闲置内存（EmptyWorkingSet），或结束不需要的进程。结束进程前请确认已保存相关工作。
进程PID 内存窗口标题

隐私清理

清除电脑上的使用痕迹：最近打开的文档、运行历史、地址栏历史、浏览器浏览记录等。清理浏览器记录前请先关闭浏览器。

软件更新

通过 Windows 官方包管理器 winget 检测已安装软件的可用更新，一键升级到最新版本。
软件当前版本 最新版本ID

工具箱

常用系统维护工具与快捷入口。修复类操作耗时较长的会弹出命令行窗口显示进度。
